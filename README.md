# 任务栏硬件与网络实时监控工具 (TaskbarMonitor)

一款轻量、精致、专为 Windows 任务栏设计的硬件性能与网络流速实时监控小工具。

---

## ✨ 核心特性

1. **实时多维指标监控**：
   - 🌐 **网络流速**：上传速度（`↑` 亮青）与下载速度（`↓` 翠绿），自适应单位（KB/s、MB/s、GB/s，彻底去除了跳动的 B/s）。
   - 💽 **磁盘读写**：实时磁盘读取速度（`读` 亮金黄）与写入速度（`写` 活力橙）。
   - ⚡ **CPU 监控**：CPU 总体使用率与核心封装温度（℃），温度过高时智能变红预警。
   - 🎮 **GPU 监控**：显卡实时核心利用率与显存利用率、核心温度（℃）。
   - 🧠 **内存占用**：物理内存占用百分比与实际已用容量（GB）。

2. **双重视觉主题与极致可读性**：
   - 🪟 **完全透明模式（原生悬浮感）**：无任何黑框与底色，文字与图标像原生时间一样悬浮在任务栏底色上，极其清爽！
   - 🌌 **磨砂胶囊模式**：精致的纯黑微磨砂卡片轮廓与半透明光泽边框，防背景干扰。
   - 🖋️ **文字深色微投影（DropShadow）**：所有文字背后自带高对比度深色微阴影，彻底杜绝壁纸高亮或反光引起的看不清问题。

3. **自由显示项勾选与智能自适应缩宽**：
   - 可在菜单或设置中自由开启/关闭：网络、磁盘、CPU、GPU、内存等任一项。
   - **智能宽度收缩**：隐藏未勾选的项后，小部件自动自适应缩短宽度，并紧紧吸附贴合在系统托盘展开按钮（`^`）左侧。

4. **可视化偏好设置与持久化**：
   - 右键提供二级快捷勾选子菜单，同时提供“⚙️ 偏好设置...”对话框，调节采样频率、水平偏移微调等。
   - 所有偏好自动保存至本地 `config.json`，下次启动与开机自启自动加载。

5. **开机自动启动**：
   - 写入 Windows 注册表 `Run` 自启项，支持一键勾选开关。

## 🚀 启动方式

- **方式一（免安装绿色版，推荐）**：
  或双击项目目录下的：
  `启动软件.bat`

- **方式二（Python 源码静默运行）**：
  双击运行：
  `运行软件.vbs`

---

## 📂 项目结构

- `main.py`：程序主入口、单实例互斥锁、系统托盘常驻图标。
- `ui_taskbar.py`：任务栏监控界面、完全透明/胶囊切换、自适应宽度、文字投影及右键菜单。
- `ui_settings.py`：可视化“偏好设置”对话框。
- `config.py`：用户配置本地持久化管理器（`config.json`）。
- `taskbar_helper.py`：Windows 任务栏与系统托盘 64 位精准定位、置顶与免抢焦点样式。
- `monitor.py`：后台独立多线程数据采集模块（PyLibreHardwareMonitor + NVML + psutil）。
- `autostart.py`：Windows 注册表开机自启管理模块。
- `build_exe.py`：一键打包脚本（打包临时文件统一存入 `cache` 目录）。
