# 任务栏硬件与网络实时监控工具 (TaskbarMonitor)

一款轻量、精致、专为 Windows 任务栏设计的硬件性能与网络流速实时监控小工具。

---

## ✨ 核心特性

1. **实时多维指标监控**：
   - 🌐 **网络流速**：上传速度（`↑` 青色）与下载速度（`↓` 绿色），自动自适应单位（B/s、KB/s、MB/s、GB/s）。
   - 💽 **磁盘读写**：实时磁盘读取速度（`读` 浅橙色）与写入速度（`写` 亮橙色）。
   - ⚡ **CPU 监控**：CPU 总体使用率与核心封装温度（℃），温度过高时智能警示变色。
   - 🎮 **GPU 监控**：NVIDIA / 独立显卡实时核心利用率与显存利用率、核心温度（℃）。
   - 🧠 **内存占用**：物理内存占用百分比与实际使用容量（GB）。

2. **完美的任务栏贴合与视觉体验**：
   - 🎯 **精确定位**：自动检测 Windows 11/10 任务栏高度与系统托盘展开图标（`^`）的位置，精准贴合在托盘区左侧空白处。
   - 🎨 **深色磨砂质感**：半透明胶囊卡片设计，与 Windows 现代深色任务栏浑然一体。
   - 🛡️ **免夺焦点**：采用 Windows `WS_EX_NOACTIVATE` 特性，日常点击或右键菜单绝不抢占全屏游戏、代码编辑器或打字的前台焦点。
   - 🔄 **自动校准**：自动响应托盘图标增减或屏幕分辨率变化，始终保持对齐。

3. **开机自动启动**：
   - 支持在软件右键菜单中一键开启或关闭“开机自动启动”（基于注册表 Run 键）。

4. **便捷交互与功能菜单**：
   - **悬停浮窗（Tooltip）**：鼠标移到监控条上，显示详尽的硬件型号（如 i7-12700KF、RTX 4060 Ti）与内存容量卡片。
   - **双击快捷操作**：鼠标左键双击监控条，秒开 Windows 任务管理器。
   - **右键功能菜单**：
     - 开机自动启动（勾选）
     - 打开任务管理器
     - 重新对齐到任务栏托盘
     - 退出程序
   - **左键微调**：按住鼠标左键可横向自由拖动微调摆放位置。

## 🚀 启动方式

- **方式一（免安装绿色版，推荐）**：
  直接双击运行：
  `TaskbarMonitor\dist\TaskbarMonitor\TaskbarMonitor.exe`
  或双击项目目录下的：
  `启动软件.bat`

- **方式二（Python 源码静默运行）**：
  双击运行：
  `运行软件.vbs`

---

## 📂 项目结构

- `main.py`：程序主入口，单实例互斥锁、系统托盘常驻图标。
- `ui_taskbar.py`：任务栏监控界面、双行四列排版、彩色区分与交互菜单。
- `taskbar_helper.py`：Windows 任务栏与系统托盘句柄定位算法、免抢焦点样式。
- `monitor.py`：后台独立多线程数据采集模块（PyLibreHardwareMonitor + NVML + psutil）。
- `autostart.py`：Windows 注册表开机自启管理模块。
- `build_exe.py`：一键打包脚本（打包临时文件统一存入 `cache` 目录）。
